# Chai Culture "Coming Soon" Page Submission

## Assignment Details
- **Role:** Frontend Developer
- **Task:** Build a "Coming Soon" Landing Page
- **Brand:** Chai Culture - "Brew the Royal Tradition"

## Design Choices
For this project, I focused on creating a **premium, royal, and elegant** digital experience that aligns with the "Chai Culture" brand.
1.  **Color Palette:** I utilized a rich scheme of **Royal Gold (#D4AF37)**, **Deep Brown (#4B2E2E)**, and **Luxurious Cream (#FFF8E7)**. This combination evokes warmth and luxury, mirroring the product's "royal tradition".
2.  **Typography:** I selected **'Playfair Display'** (Serif) for headings to provide a sophisticated, regal feel, and **'Lato'** (Sans-serif) for body text to ensure modern readability and clean aesthetics.
3.  **User Experience:** I implemented smooth **Framer Motion animations** (fade-ins, drifts) to give the page a dynamic, "alive" feel without being overwhelming. The layout is fully **responsive**, ensuring the premium experience translates perfectly from desktop to mobile.

## Features Implemented
- [x] **Responsive Design:** Looks great on mobile, tablet, and desktop.
- [x] **Brand Alignment:** Logo, Tagline, and colors match the royal theme.
- [x] **Interactive Elements:**
    - Email Signup form with validation and success state.
    - Hover effects on buttons and social icons.
    - Subtle background animations.
- [x] **Performance:** Optimized assets and code splitting via React.

## How to Run Locally
1.  Clone the repository.
2.  Run `npm install`.
3.  Run `npm start` to view the app at `http://localhost:3000`.

## Deployment
This project is ready to be deployed to **Vercel** or **Netlify**.
